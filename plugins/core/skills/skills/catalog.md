# Catalog

Every domain and skill of this marketplace, with the switch that turns it on in a project. A skill works only with the skills it needs on. Generated by `dev/sync.py` from the plugins: don't edit.

## core

Working standards for any project: musts with proofs and guides, receipts, verification against the project's own versions, fresh reviews and honest reports, the documentation layout, version notes, and the switches that choose a project's domains and skills.

- Switch: `CORE_STANDARDS`. Read rule: `Read(~/.claude/plugins/cache/*/core/**)`.
- Builds on: nothing. Comes on with: game-design, modeling, unity-dev.

| Skill | Does | Needs | Switch |
|---|---|---|---|
| `core:project-docs` | Sets up or tidies a project's documentation so people and Claude share one source of truth - README.md and CLAUDE.md as indexes, knowledge in docs/, Claude instructions in CLAUDE.md and .claude/rules/. | - | `CORE_SKILL_PROJECT_DOCS` |
| `core:skills` | Shows which domains and skills of this marketplace a project has on, and turns them on or off in its settings, for the whole team or for you alone. Without arguments it looks at the project and turns on what it needs. | - | `CORE_SKILL_SKILLS` |
| `core:version-notes` | Researches what changed in a project's key technologies between the versions Claude knows well and the versions the project uses, and records what matters for it in docs/<technology>-version-notes.md. | - | `CORE_SKILL_VERSION_NOTES` |

- Switch: `UNITY_DEV_STANDARDS`. Read rule: `Read(~/.claude/plugins/cache/*/unity-dev/**)`.
- Builds on: core, game-design, modeling.
